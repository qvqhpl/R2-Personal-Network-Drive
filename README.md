# ☁️ HPL的专用云 (HPL Cloud Drive)

基于 **Cloudflare Workers** + **Cloudflare R2** 构建的专属轻量级云盘系统。

---

## ✨ 核心特性

- 🔒 **全站密码保护**：进入需输入密码验证，输错原生弹窗警告，密码正确无缝进入。
- 📊 **容量与文件自检**：登录自动拉取 R2 存储状态，实时显示文件总数与已用存储。
- ⚡ **秒级上传与下载**：原生文件选择与电脑批量拖拽上传，手机相册即选即传。
- 🛑 **取消传输防卡死**：上传及下载进度弹窗中配备显式**“取消传输”**按钮，随时安全中断任务，杜绝传输假死。
- 🔍 **实时文件名搜索**：支持在文件列表中即时按名称筛选文件。
- 🗑️ **彻底删除与安全退出**：原生二次确认彻底删除文件，一键退出登录清理会话。

---

## 🚀 极速部署指南

### 方式一：Cloudflare 网页直接部署（最快推荐）
1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)，在 **R2** 中新建一个存储桶（如 `my-cloud-drive`）；
2. 在 **Workers & Pages** 中创建一个新的 Worker；
3. 进入该 Worker 的 **编辑代码 (Edit code)**，全选清空并粘贴 `index.js` 的完整代码，点击右上角 **部署 (Deploy)**；
4. 进入该 Worker 的 **设置 (Settings)** -> **绑定** -> **R2 存储桶绑定**：
   - 变量名称：`BUCKET`（大写）；
   - R2 存储桶：选择第一步创建的存储桶；
5. 添加变量：AUTH_PASSWORD，值：（你的自定义密码）如未添加，默认密码为 `admin123456` ；
